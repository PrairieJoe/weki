# Weki v1.3.1 - 검색 입력과 구성요소 설치 후 재시작 안정화

## 검색 입력 안정성

- 설정에서 고품질 검색 구성요소를 전체 설치한 직후 검색 화면으로 이동해도 검색 입력창을 클릭하고 바로 입력할 수 있습니다.
- Electron 창 포커스와 렌더러 웹뷰 포커스를 함께 복구해, 창을 다른 앱으로 전환했다가 돌아오거나 설치가 진행 중인 상태에서도 입력이 지연되지 않습니다.
- 검색 입력 중 백그라운드 상태 갱신이 화면과 입력창을 교체하지 않아 `Enter` 전에 입력한 검색어와 한글 조합이 유지됩니다.
- 설치 알림이 검색 입력창의 포인터 이벤트를 가로채지 않도록 배치와 상호작용을 조정했습니다.

## 구성요소 설치 및 재시작

- 구성요소 설치 중 검색 화면으로 이동하면 자동 재시작을 보류하고, 설치가 끝난 뒤 설정에서 다시 시작할 수 있도록 안내합니다.
- 로컬 서버는 시작 직후 준비 메시지를 수신하고 첫 실행의 렌더러 업그레이드 시간을 고려해 제한 시간 안에 준비 상태를 판정합니다.
- Windows에서 구성요소 상태·manifest·설치 폴더를 교체할 때 일시적인 `EPERM`·`EBUSY`·`EACCES` 파일 잠금을 자동 재시도합니다.
- 검색 포커스 요청과 렌더러 입력 이벤트를 `.runtime/logs/ui-focus.log`에 기록해 실사용 환경의 포커스 문제를 확인할 수 있습니다.
