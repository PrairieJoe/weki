# Weki 이용자 테스트 체크리스트

이 문서는 최근 이용자 테스트에서 제기된 설정·runtime·MYBOX 관련 질문을 실제 사용자 흐름으로 재확인하기 위한 체크리스트입니다. 다운로드 행위 자체를 문제로 삼지 않습니다. 클라우드 또는 MYBOX를 통한 설치가 필요한 경우에도, 테스트의 초점은 **어떤 구성요소가 보이는지, 설치 가능한지, 설치 후 어떤 상태와 처리 모드가 되는지**입니다.

## 테스트 목적

- 최초 설치 상태에서 고품질 검색 구성요소의 의존관계가 사용자에게 오해 없이 전달되는지 확인합니다.
- semantic model, semantic reranker, document renderer의 설치·업데이트·재시작 상태를 확인합니다.
- 세 구성요소 설치 이후 기본 처리 모드가 의도대로 Local AI로 전환되는지 확인합니다.
- MYBOX 백업·카탈로그 동기화와 원본 지연 복원 흐름이 비전공자에게 이해되는지 확인합니다.
- MYBOX 접근·배포본 문제와 문서 원본 다운로드 문제를 서로 다른 이슈로 구분합니다.
- 신규 사용자가 실제 데이터를 변경하지 않고 문서 등록부터 MYBOX까지의 9단계 핵심 흐름을 이해할 수 있는지 온보딩 투어에서 확인합니다.
- Gemini Key를 화면에 다시 표시하지 않고, 상태·로그에도 노출하지 않으며 외부 전송 범위와 fallback 정책이 명확한지 확인합니다.

## 준비 조건

가능하면 다음 환경을 각각 준비합니다.

1. 구성요소를 하나도 설치하지 않은 신규 설치 환경
2. semantic model만 설치·적용된 환경
3. 세 구성요소가 모두 설치·적용된 환경
4. 새 버전 manifest가 있는 업데이트 환경
5. 공개 배포본은 없고 MYBOX 배포본만 있는 환경
6. MYBOX 토큰이 없거나 검증에 실패한 환경
7. 기존 문서가 이미 등록된 환경과 문서가 하나도 없는 환경
8. 완료 표식이 없는 신규 설치 프로필과 온보딩을 완료한 설치 프로필

테스트 중에는 화면 캡처, 앱 버전, 구성요소 버전, 상태 문구, 수행한 클릭 순서를 함께 기록합니다. 토큰과 문서 원문은 캡처·공유하지 않습니다.

## 이용자에게 직접 물어볼 질문

테스트 진행자는 다음 질문을 그대로 사용해도 됩니다.

- 세 구성요소 중 지금 설치할 수 있는 것과 아직 배포 준비 중인 것을 구분할 수 있나요?
- `전체 설치`를 누르면 어떤 일이 어떤 순서로 진행될 것 같나요?
- 세 구성요소가 모두 준비된 뒤 기본 처리 모드가 바뀐다는 설명이 충분한가요?
- 기존 문서도 자동으로 다시 처리될 것이라고 오해하지 않았나요?
- MYBOX 백업, 검색 DB 동기화, 원본 지연 복원이 각각 어떻게 이어지는지 설명할 수 있나요?
- v1.2.0의 로컬 `.weki` 파일을 v1.2.1에서 복원할 수 없고 자동 삭제하지 않는다는 안내가 명확한가요?
- 사용자 설정 화면의 검색 색인 관리 UI는 제거됐지만, 내부 검색 색인 재생성 API는 마이그레이션·복구용으로 유지된다는 점이 명확한가요?
- 내부 검색 색인 재생성 API와 전체 문서 재처리의 차이, 그리고 전체 문서 재처리가 v1.3.0 검토 항목이라는 점이 명확한가요?
- `MYBOX 배포본`과 `MYBOX에서 원본 가져와 열기`가 서로 다른 기능이라는 점이 명확한가요?
- 첫 화면에서 온보딩 투어가 선택형으로 시작되고, 무엇을 설명하는 기능인지 이해할 수 있었나요?
- `사용 가이드`를 누르면 투어가 1단계부터 다시 시작된다는 점을 알 수 있었나요?
- 투어가 실제 문서 등록·검색·설정 변경·MYBOX 동기화를 하지 않는다는 점이 명확했나요?
- 건너뛰기·닫기·완료 후 투어 시작 화면으로 돌아온다는 점과 키보드 조작이 충분히 이해되었나요?
- `정상 작동`, `일부 기능 제한`, `배포 준비 중` 중 이해하기 어려운 표현이 있나요?

## 판정 기준

- 필수 시나리오에서 P0/P1 수준의 데이터 손실·잘못된 외부 전송·복구 불가 문제가 없어야 합니다.
- 신규 설치 사용자가 3개 구성요소의 상태와 설치 가능 여부를 별도 설명 없이 구분할 수 있어야 합니다.
- 사용자가 구성요소가 없을 때도 경량 처리와 로컬 검색을 계속 사용할 수 있어야 합니다.
- 세 구성요소 적용 후 새 문서의 기본 모드가 Local AI가 되는 흐름과 기존 문서가 자동 재처리되지 않는다는 정책을 이해할 수 있어야 합니다.
- MYBOX 인증 실패가 로컬 기능 전체 중단으로 오해되지 않아야 합니다.
- 사용자가 로컬 `.weki` 파일을 현재 복원 경로로 오해하지 않아야 하며, MYBOX 카탈로그 동기화와 원본 지연 복원 흐름을 구분할 수 있어야 합니다.
- 전체 문서 재처리가 현재 릴리스에서 실행되는 기능으로 안내되지 않아야 합니다.
- 내부 검색 색인 재생성 API가 사용자 설정 기능이나 전체 문서 재처리로 오해되지 않아야 합니다.
- 온보딩 투어가 신규 설치에서 선택형으로 시작되고, 9단계의 핵심 흐름을 실제 작업 없이 설명해야 합니다.
- 사용자가 `사용 가이드`로 1단계부터 재생할 수 있고, 기존 완료 사용자는 자동 재생되지 않으며, 건너뛰기·닫기·완료 후 시작 화면으로 복귀해야 합니다.
- 온보딩 중 문서·검색·설정·MYBOX 데이터가 변경되지 않고, 완료 표식이 로컬 설치 프로필에만 남아야 합니다.
- 포커스가 대화상자 안에 유지되고 Esc 종료와 종료 후 포커스 복귀가 동작해야 합니다.
- 데스크톱 대화상자 드래그가 화면 안쪽으로 제한되고, 모바일에서는 중앙 정렬되어야 합니다.
- 정적 검색 결과·근거 예시가 실제 문서·검색 변경 없이 표시되어야 합니다.
- Gemini Key가 화면에 다시 표시되지 않고, 외부 AI OFF가 신규 작업에 적용되며, 모든 OFF→ON 전환에 동의 확인이 있어야 합니다.
- `healthy` 같은 내부 상태값이 이용자 화면에 그대로 노출되지 않아야 합니다.
