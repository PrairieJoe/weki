# Weki v1.2.2 릴리스 노트

- 신규 설치 온보딩 투어를 실제 이용 흐름에 맞춰 `문서 등록 → 검색 → 결과·근거 → 처리 모드 설정 → MYBOX` 순서로 재배치했습니다.
- 온보딩 배경 오버레이를 중성 회색 반투명 스타일로 변경해 짙은 청색으로 인한 시각적 피로를 낮췄습니다.
- 설정 · 운영 화면의 고품질 검색 구성요소 카드에서 상태와 설치 작업을 고정 열로 정렬했습니다.
- 설치 버튼이 없는 구성요소도 작업 열을 예약해 다른 행의 상태 위치가 흔들리지 않도록 했습니다.
- 온보딩 단계 순서, 온보딩 중 쓰기 요청 부재, 런타임 카드의 실제 화면 좌표를 검증하는 회귀 테스트를 추가했습니다.
- 서버 API, runtime 구성요소 처리 순서, 설치·업데이트·재시작·MYBOX 동작은 변경하지 않았습니다.
